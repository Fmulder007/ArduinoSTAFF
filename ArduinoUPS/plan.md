# ArduinoUPS — RP2040-Zero / PIO-эксперимент

**Статус:** испытательная версия, перенесены только четыре управляющих выхода и RUN.  
**Исходная версия:** ветка `arduino-ups-four-output-driver`.  
**Текущая ветка:** `arduino-ups-rp2040-pio`.  
**Плата:** Waveshare RP2040-Zero, RP2040.  
**Среда:** Arduino IDE + Arduino-Pico core by Earle Philhower.

## 1. Цель

Проверить генерацию четырёх независимых сигналов плеч драйверов аппаратным PIO без участия CPU в моменты переключения.

В этой ветке намеренно отсутствуют измерение АКБ, батарейная защита, реле зарядки, дисплей, энкодер и остальные будущие функции. Сейчас реализованы только четыре выхода, вход RUN и исходная логика запуска/остановки генератора.

## 2. Распиновка

| RP2040-Zero | Назначение |
|---|---|
| GP0 | DRIVER_A_H — верхнее плечо драйвера A |
| GP1 | DRIVER_A_L — нижнее плечо драйвера A |
| GP2 | DRIVER_B_H — верхнее плечо драйвера B |
| GP3 | DRIVER_B_L — нижнее плечо драйвера B |
| GP4 | RUN — HIGH: генерация нужна; LOW: сеть появилась |

GP0–GP3 — четыре последовательных вывода, управляемые одной инструкцией PIO `SET PINS`. RUN читает только функция `updateRunStatus()`.

## 3. Временная последовательность

Параметры перенесены из четырёхвыходной AVR-ветки:

- частота — 50 Гц;
- полный период — 20 мс;
- полупериод — 10 мс;
- общее межполупериодное окно — 1 мс;
- активный импульс верхнего плеча — 9 мс;
- защитная пауза внутри драйвера — 50 мкс;
- остаточное межполупериодное ожидание — 900 мкс.

При тактовой частоте PIO 2,5 МГц один цикл составляет 0,4 мкс:

| Интервал | Такты PIO |
|---|---:|
| 50 мкс | 125 |
| 9 мс | 22500 |
| 900 мкс | 2250 |
| Полный период | 50000 |

`clk_sys` по умолчанию 125 МГц; делитель PIO равен ровно 50. Скетч проверяет, что системная частота кратна 2,5 МГц, и при неподходящей настройке оставляет все выходы LOW.

## 4. Таблица выходных состояний

Бит 0 = GP0/A_H, бит 1 = GP1/A_L, бит 2 = GP2/B_H, бит 3 = GP3/B_L.

| Состояние | Биты GP3…GP0 | Включённые плечи |
|---|---:|---|
| NORMAL | 1010 | A_L + B_L |
| A_PREPARE | 1000 | B_L |
| A_ACTIVE | 1001 | B_L + A_H |
| B_PREPARE | 0010 | A_L |
| B_ACTIVE | 0110 | A_L + B_H |
| ALL_OFF | 0000 | все выключены |

В каждой команде PIO меняет сразу четыре бита. Верхнее и нижнее плечи одного драйвера никогда не включаются одновременно.

## 5. Запуск и остановка

- При старте все четыре GPIO сначала устанавливаются в LOW.
- PIO загружает временные параметры, устанавливает NORMAL и ожидает разрешения.
- После стартовой задержки 1000 мс выполняется первое чтение RUN.
- RUN=HIGH запрашивает генерацию.
- RUN=LOW должен непрерывно сохраняться 5000 мс, прежде чем будет подтверждено появление сети.
- До истечения 5000 мс кратковременный RUN=LOW не останавливает генерацию.
- При подтверждении RUN=LOW устанавливается STOP-флаг PIO.
- PIO завершает текущую последовательность A+B и останавливается в NORMAL на границе периода.
- Возврат RUN=HIGH снимает STOP-флаг, после чего PIO начинает следующий полный период.

Для проверки используется внутренний IRQ-флаг PIO0. Он не подключён к внешнему выводу. Программа PIO ожидает `WAIT 0 IRQ 0`: высокий флаг означает STOP, низкий — разрешение. Полярность 0 выбрана намеренно: такой WAIT не очищает флаг при выполнении условия.

## 6. Архитектура PIO

- Используется PIO0 и один state machine.
- PIO-программа занимает все 32 слова памяти инструкций PIO0.
- Программа загружается с фиксированного offset 0, поскольку адреса JMP рассчитаны на это расположение.
- PIO1 остаётся свободным.
- Временные счётчики загружаются один раз из TX FIFO в Y, ISR и OSR.
- После запуска PIO самостоятельно выполняет все переключения; CPU не обслуживает фронты и не пишет в GPIO во время генерации.
- Исходник программы — `driver_pio.pio`; предварительно собранная таблица — `driver_pio.h`.

В первой межполупериодной паузе есть дополнительная инструкция NOP. На границе периода выполняется WAIT. Эти два такта компенсируют друг друга, поэтому обе паузы остаются по 900 мкс, а полный период — ровно 20 мс.

## 7. Сборка в Arduino IDE

Установить ядро **Raspberry Pi Pico/RP2040/RP2350 by Earle F. Philhower** через Boards Manager и выбрать **Waveshare RP2040 Zero**.

В Arduino-Pico пользовательский `.pio` автоматически не ассемблируется при обычной сборке скетча. Поэтому готовая таблица инструкций уже включена в `driver_pio.h`. Если изменять `driver_pio.pio`, соответствующий заголовок нужно пересобрать PIOASM и обновить в репозитории.

## 8. Проверка на стенде

До подключения силовых драйверов:

1. Проверить GP0–GP3 осциллографом при RUN=HIGH.
2. Убедиться, что каждый переход одновременно меняет соответствующий четырёхбитный шаблон.
3. Проверить 50 мкс защиты внутри каждого драйвера.
4. Проверить импульсы верхних плеч 9 мс.
5. Проверить 900 мкс остаточного межполупериодного ожидания и период 20 мс.
6. Во время работы подать RUN=LOW менее чем на 5 секунд — генерация должна продолжиться.
7. Удерживать RUN=LOW более 5 секунд — генератор должен завершить текущий период A+B и вернуться в NORMAL.
8. Проверить повторный запуск при RUN=HIGH.

Эта версия предназначена для измерения временной стабильности PIO на логических выходах, без подключения силовой части.
