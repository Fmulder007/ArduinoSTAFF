# ArduinoUPS

## Назначение

Разработка простого автономного ИБП на Arduino Nano (ATmega328P), аккумуляторе, трансформаторе от ИБП и силовых MOSFET.

Целевые нагрузки:
- обычное потребление: примерно 10–20 Вт;
- максимальная мощность: ориентировочно 100–200 Вт.

## Текущий макет

- Простой двухтактный меандр 50 Гц; SPWM пока не используется.
- Генерация выполняется аппаратным Timer1 Arduino Nano.
- Dead time встроен в расписание событий Timer1.
- Первый импульс каждого запуска — OUT_A (D6); штатная остановка происходит только после полного импульса OUT_B (D7) и заключительного dead time. Число импульсов обоих плеч одинаковое.
- Вход A0/RUN подключается к датчику наличия сети: HIGH — сети нет, генератор нужен; LOW — сеть появилась. При HIGH генератор запускается сразу после стартовой инициализации. Для остановки LOW должен сохраняться непрерывно 5 секунд; кратковременное возвращение HIGH отменяет отсчёт.
- Измерение напряжения аккумулятора выполняется на A6/ADC6 раз в секунду.
- Для АЦП выбрана внутренняя опора `analogReference(INTERNAL)` (номинально 1,1 В). Коэффициент пересчёта требует калибровки.
- Единый байт `generatorBlockFlags` хранит причины запрета генерации: 0 — запретов нет, любое ненулевое значение блокирует генерацию. Каждый модуль изменяет только свой бит.
- D8 зарезервирован под логический сигнал управления реле зарядки; алгоритм зарядки пока не реализован.

## Распиновка

| Вывод | Сигнал | Назначение |
|---|---|---|
| A0 | RUN | Датчик наличия сети |
| A1 | PERMIT | Резерв для будущего внешнего разрешения |
| A6 | BAT_SENSE | Измерение напряжения АКБ через делитель |
| D5 | DRIVER_EN | Общее разрешение драйверов |
| D6 | OUT_A | Управление плечом A |
| D7 | OUT_B | Управление плечом B |
| D8 | CHARGE_RELAY | Логическое управление реле зарядки |

D8 управляет входом драйвера/ключа реле, а не катушкой напрямую. На D5–D8 предусматриваются внешние подтяжки к GND. Подробная карта резервирования остальных выводов находится в `plan.md`.

## Настройки в ArduinoUPS.ino

В начале файла находятся настройки частоты, dead time, времени подтверждения появления сети, параметров АЦП и делителя, а также пороговые значения:
- `BATTERY_GENERATOR_STOP_VOLTAGE` — нижний порог запрета генерации;
- `BATTERY_GENERATOR_RECOVERY_VOLTAGE` — порог восстановления разрешения;
- `BATTERY_CHARGE_ON_VOLTAGE` — будущий порог включения зарядки;
- `BATTERY_CHARGE_OFF_VOLTAGE` — будущий порог выключения зарядки.

Нулевые значения порогов АКБ временно отключают соответствующую логику для макетных испытаний. Перед подключением реальной батареи нужно определить её номинальное напряжение и химию, проверить делитель под максимальное напряжение сборки и откалибровать внутреннюю опору АЦП.

## Безопасность и дальнейшая разработка

Сейчас это испытательный макет логической генерации, а не готовый ИБП. До подключения силовых MOSFET, трансформатора и сети необходимо отдельно разработать и проверить аппаратное отключение драйверов, защиту от сверхтока/короткого замыкания, переключение источников и безопасное зарядное устройство.

Дальнейшие этапы:
1. Проверить временные диаграммы OUT_A/OUT_B осциллографом.
2. Определить аккумулятор и откалибровать измерение A6.
3. Реализовать управление зарядным реле D8 по заданным порогам.
4. Добавить остальные датчики, защитные причины и журнал событий.
5. Реализовать переключение сети/инвертора и индикацию/меню.
