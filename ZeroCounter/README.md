# ZeroCounter

Первая версия частотомера для Waveshare RP2040-Zero.

Сейчас реализован только ВЧ-вход B. НЧ-вход A будет добавлен отдельно.

## Настройки

В начале файла ZeroCounter.ino:

- **REF_FREQ_HZ** — частота внешнего TCXO в герцах.
- **PRESCALER_K** — коэффициент внешнего прескалера входа B, от 1 до 256.

Начальные значения: 10 МГц и ÷64.

## Распиновка

| GPIO | Назначение |
|---:|---|
| GP14 | OLED SDA, I2C1 (Wire1) |
| GP15 | OLED SCL, I2C1 (Wire1) |
| GP7 | Вход B, выход внешнего прескалера, PWM3B |
| GP9 | Вход опоры TCXO, PWM4B |
| GP12 | Готовность термостата опоры, HIGH = готов |

Индикатор CNT показывает наличие импульсов на входе B. Индикатор REF повторяет состояние входа готовности термостата.

Оба измерительных входа заведены на входы B разных PWM-срезов RP2040. Выводы OLED и термостата не пересекаются с измерительными входами.

## Принцип измерения

Для этой версии используются аппаратные счётчики PWM в режиме подсчёта каждого положительного фронта входа B. Это аппаратный счётчик периферии RP2040, а не обработка каждого импульса процессором через digitalRead() или GPIO-прерывание.

Один PWM-счётчик считает импульсы после внешнего прескалера, второй — циклы TCXO. 16-битные счётчики расширяются программными счётчиками переполнений.

Частота рассчитывается целочисленно:

**f = delta_input × PRESCALER_K × REF_FREQ_HZ / delta_reference**

Оба аппаратных счётчика продолжают считать непрерывно. Результат пересчитывается каждые 100 мс по всему накопленному интервалу. При отсутствии импульсов на входе B в течение 100 мс измерение сбрасывается.

В расчёте нет float и double.

## OLED

SSD1306 128×64, I2C1 (Wire1) на GP14/GP15, скорость 100 кГц, адрес по умолчанию 0x3C.

Драйвер OLED включён непосредственно в скетч. Дополнительные графические библиотеки не нужны. Частота отображается целым числом герц; между группами по три цифры сделан увеличенный интервал.

## Сборка

Используется Arduino-Pico core by Earle Philhower и плата Waveshare RP2040-Zero.

FQBN для Arduino CLI: rp2040:rp2040:waveshare_rp2040_zero.

Сборка из корня репозитория:

    arduino-cli compile --fqbn rp2040:rp2040:waveshare_rp2040_zero ZeroCounter

Нужен именно RP2040 Arduino core с Pico SDK headers (hardware/pwm.h, hardware/irq.h). Скетч не предназначен для AVR/GyverCore.

Внешние библиотеки не требуются: используется стандартный I2C-интерфейс Wire1 из Arduino-Pico core.

## Примечание по входной частоте

В режиме edge-count PWM периферия RP2040 требует, чтобы длительности высокого и низкого уровней входного сигнала были больше периода clk_sys. При стандартном clk_sys = 125 МГц это более 8 нс для каждого уровня.

Поэтому на GPIO7 должен поступать уже сформированный сигнал после внешнего прескалера. TCXO подаётся на GPIO9 в цифровой форме.
